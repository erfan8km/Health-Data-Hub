==================================================
1. CORE PURPOSE OF THE PROJECT
==================================================

This website is an EPIDEMIOLOGY AND HEALTH DATA HUB / registry catalogue.

It is NOT a repository for individual-level patient data.

The website must NEVER store, expose, upload, or distribute raw individual registry records.

The intended user flow is:

1. User opens the website.
2. User chooses Persian or English.
3. User sees the registry catalogue.
4. User searches/filters registries.
5. User opens a registry.
6. User sees metadata about that registry.
7. User sees available/general variable information if it has actually been provided.
8. User sees a clear explanation that the website is metadata-only.
9. User can click the official university/registry source link.
10. Actual registry data download/access happens only on the official source website.

Do NOT invent registry metadata.

If a value is unknown, display:
- Persian: «اطلاعات در دسترس نیست»
- English: "Not available"

Never display fake 0 values.
